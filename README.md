Text Encryption & Integrity Checker

A Python project developed as part of my academic learning.

Features

• Caesar Cipher text transformation
• XOR operation with Base64 encoding
• SHA-256 hashing
• Decryption to recover the original message
• Basic ciphertext integrity comparison

Technologies

• Python
• Base64
• Hashlib (SHA-256)

Note

This project demonstrates basic cryptographic concepts for learning purposes. The encryption methods used are not suitable for securing sensitive data in real-world applications.
